# 🏝️ MoodIsle 情绪小岛 · 情绪日记与自我关怀

AI Coding 附加题作品 · 纯前端实现，无后端、无第三方依赖、无数据上传。

**在线访问**：https://leiyummy111.github.io/leiyiming-diary/

## 产品设计

针对「年轻人情绪波动频繁、缺乏低门槛记录与疏解工具」的痛点，产品围绕
**记录 → 理解 → 调节** 三步闭环设计为六个模块：

| 模块 | 能力 |
|------|------|
| 🏠 今天 | 情绪打卡 Hero、情绪稳定度 / 连续天数 / 高频触发统计、情绪曲线、AI 今日观察、此刻推荐 |
| ✍️ 记录 | 27 种情绪分级选择、强度滑块、16 类触发因素标签、边写边分析（触发识别 + 认知偏差提示）、语音转写（Web Speech API） |
| 📊 洞察 | 7/30/90 天情绪趋势、情绪构成甜甜圈、触发因素排行（可下钻）、时段 × 星期热力图、12 周记录日历、AI 规律归纳 |
| 🌿 关怀 | 呼吸练习（4-7-8 / 箱式 / 舒缓）、正念冥想计时、Web Audio 实时合成环境音景（雨声 / 海浪 / 森林 / 夏夜 / 咖啡馆）、按情绪定制的音乐处方与运动处方 |
| 📖 日记 | 时间线浏览、搜索、情绪筛选、单条 AI 复盘、删除、JSON 导入导出 |
| 💬 陪伴 | 本地情绪理解引擎驱动的倾听对话：共情回应、触发因素关联、认知偏差（CBT）温和提示、危机词安全响应 |

## 技术说明

- **零依赖**：手写 SVG 图表（平滑贝塞尔曲线 / 甜甜圈 / 热力图）、手写 Web Audio 音景合成，不加载任何外部库。
- **数据全本地**：localStorage 存储，首次访问自动生成 60 天示例数据便于体验，可一键清除；支持 JSON 导出 / 导入。
- **情绪理解引擎**：基于关键词 + 权重的触发因素识别、7 类认知偏差检测（过度概括 / 灾难化 / 应该式思维等）、统计规律自动归纳（星期 / 时段 / 触发因素 / 波动性），完全离线运行。
- **安全兜底**：检测到危机相关表达时，优先引导联系专业支持（全国 24 小时心理援助热线 12356）。
- **响应式**：桌面侧边导航，移动端底部 Tab，适配 375–1440px。

## 设计语言

参考 MIMO 的视觉体系：柔光渐变背景、玻璃拟态卡片、大圆角、低饱和紫粉品牌色、
入场微动效与呼吸感动效。
